# Sentra

Sentra is an urban behavioral risk intelligence system for real-time surveillance, suspicious activity detection, evidence capture, and rapid alerting.

## What Sentra Does

- Monitors live camera feeds for people, weapons, trespass, and suspicious behavior
- Highlights high-priority incidents for faster operator response
- Captures evidence during threat events for review and reporting
- Presents a polished command dashboard for demos and operational monitoring

## Brand Description

Sentra stands for a modern city-safety platform that combines behavioral analytics, live monitoring, and incident intelligence into one command-ready interface.

## Run The Project

```powershell
.\.venv\Scripts\python.exe webapp.py
```

Then open `http://127.0.0.1:5000`.

The runtime settings are stored in `sentra_settings.json`.
